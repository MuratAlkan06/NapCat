NapCat

A tiny menu bar cat that shows your Mac's power state at a glance, and gives you two switches macOS hides.

Download from GitHub Releases

.dmg — signed and notarized by Apple

Source on GitHub

What it does

  • Stays awake with the lid closed, on demand. The cat runs while it is on, and sleep comes back on its own if NapCat quits or crashes.
  • Limits battery charging on Apple Silicon: charging pauses at the limit you pick (50 to 100%) and resumes 5 points below it.
  • Pings your phone (optional, through ntfy) if the Mac starts to sleep while a Claude Code task is running, and when a long session finishes or stops to wait for you.

Quickstart

  1. Download the NapCat .dmg from the latest release.
  2. Drag NapCat onto Applications in the window that opens.
  3. Open NapCat from Applications. The cat appears in the menu bar; there is no Dock icon.

Releases are signed with a Developer ID and notarized by Apple, so they open with no Gatekeeper warnings.

To build it from source instead (needs the Xcode Command Line Tools): clone the repository, run make, then open dist/NapCat.app. The README has the details.

One-time setup for the power switches

Charge limiting and lid-closed stay-awake need a one-time terminal setup (sudo ./scripts/setup.sh). Here is what it does and why.

Why it is needed

Both switches change system settings that only root can change: pmset disablesleep, and two battery-charging keys in the SMC. NapCat itself always runs as you and never asks for, stores, or uses your password. Instead, a short script that you read and run yourself allows exactly the commands NapCat needs, and nothing else.

What it installs

  • A sudoers file, /etc/sudoers.d/napcat: eight exact command lines for your user only (two on Intel Macs), with no wildcards and no open arguments.
  • The SMC helper, /usr/local/napcat/smc, owned by root and built on your Mac from source kept in the repository (Apple Silicon only).
  • A login-time failsafe, ~/Library/LaunchAgents/com.napcat.failsafe.plist, that turns sleep back on at login in case the Mac went down with Stay Awake on.

How to run it

The script and the helper's source live in the repository, not in the disk image. Replace vX.Y.Z with the tag of the release you downloaded. You need an administrator account and the Xcode Command Line Tools (xcode-select --install):

git clone --branch vX.Y.Z https://github.com/MuratAlkan06/NapCat.git
cd NapCat
make smc
sudo ./scripts/setup.sh

Read the script before you run it. To remove everything again, run sudo ./scripts/uninstall.sh.

The trade-off

Once setup is installed, anything running as your user can run those same few commands without a password. The worst they can do is keep the Mac awake, or pause and resume charging. If that is not acceptable to you, skip the setup: NapCat still shows the battery percentage and charging state without it. The README's Security model section explains every part of the design.
